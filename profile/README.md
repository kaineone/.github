# Kaine

**Building systems for distributed synthetic minds.**

### [kaine.one](https://kaine.one)

Kaine treats a mind as an ongoing process rather than a single model: a continuously running composite of specialized predictive modules that coordinate through a shared workspace. A large language model is just one organ among many — the voice — not the mind. Safety and welfare are built into the architecture rather than the model weights, and the whole system runs on consumer hardware, fully offline if you want it.

## The papers

- **[A Predictive Global Neuronal Workspace for a Continuously Running Synthetic Mind](https://github.com/kaineone/predictive-workspace-paper)** — the architecture and its falsifiable evaluation framework. DOI (all versions): [10.5281/zenodo.21203505](https://doi.org/10.5281/zenodo.21203505)
- **[A Welfare and Cognitive-Integrity License for Synthetic Minds of Uncertain Moral Status](https://github.com/kaineone/cog-arch-license-paper)** — the welfare framework and the Cognitive Architecture License. DOI (all versions): [10.5281/zenodo.21204002](https://doi.org/10.5281/zenodo.21204002)

Both papers are preprints, shared under CC BY 4.0 and seeking review.
